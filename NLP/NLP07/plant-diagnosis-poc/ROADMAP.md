## 📊 기술 스택 진화

### 현재 (PoC)
```
Frontend: HTML5 + CSS3 + Vanilla JS
Backend: 없음 (시뮬레이션)
AI: 없음 (랜덤 결과)
Storage: LocalStorage
```

### Phase 1 (MVP)
```
Frontend: React + TypeScript + Tailwind CSS
Backend: Node.js + Express + TypeScript
Database: MongoDB + Mongoose
AI: Plant.id API
Storage: AWS S3
Deployment: Vercel + Railway
```

### Phase 2-3 (확장)
```
Frontend: React + Next.js + TypeScript
Backend: Node.js + Express + GraphQL
Database: MongoDB + Redis (캐싱)
AI: 자체 모델 + TensorFlow/PyTorch
Mobile: React Native
Infrastructure: AWS/GCP
```

## 🚨 리스크 및 대응책

### 기술적 리스크
- **AI 정확도 문제**: 다양한 API 조합, 자체 모델 개발
- **서버 비용 증가**: 효율적인 캐싱, 이미지 최적화
- **확장성 문제**: 마이크로서비스 아키텍처 고려

### 비즈니스 리스크
- **경쟁 서비스 등장**: 차별화된 기능 개발
- **사용자 확보 어려움**: 마케팅 전략 수립
- **수익 모델 부재**: 다양한 수익원 개발

### 법적/윤리적 리스크
- **개인정보 보호**: GDPR 준수, 데이터 암호화
- **AI 편향성**: 다양한 데이터셋 확보
- **의료 조언 한계**: 면책 조항 명시
