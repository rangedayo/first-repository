# 식물 진단 PoC 테스트 가이드

## 🚀 서버 실행

현재 HTTP 서버가 포트 8000에서 실행 중입니다.

**접속 URL**: http://localhost:8000

## 📋 테스트 시나리오

### 1. 메인 페이지 테스트
- [x] 브라우저에서 http://localhost:8000 접속
- [x] 반응형 디자인 확인 (모바일/데스크톱)
- [x] "지금 진단하기" 버튼 클릭 → 업로드 페이지 이동 확인

### 2. 업로드 페이지 테스트
- [x] 드래그 앤 드롭 기능 테스트
- [x] 파일 선택 버튼 테스트
- [x] 파일 형식 검증 (JPG, PNG만 허용)
- [x] 파일 크기 검증 (10MB 제한)
- [x] 이미지 미리보기 기능
- [x] "분석 시작" 버튼 활성화/비활성화

### 3. 분석 프로세스 테스트
- [x] 로딩 모달 표시
- [x] 진행률 시뮬레이션
- [x] 로컬 스토리지에 데이터 저장
- [x] 결과 페이지로 자동 이동

### 4. 결과 페이지 테스트
- [x] 업로드한 이미지 표시
- [x] 랜덤 진단 결과 표시
- [x] 신뢰도 애니메이션
- [x] 원인 분석 표시
- [x] 해결책 제공
- [x] "다시 진단하기" 버튼

## 🎯 PoC 검증 포인트

### ✅ 완료된 기능
1. **UI/UX 플로우**: 메인 → 업로드 → 결과 페이지 완전한 플로우
2. **이미지 업로드**: 드래그앤드롭, 파일선택, 검증, 미리보기
3. **분석 시뮬레이션**: 로딩 상태, 진행률, 결과 생성
4. **결과 표시**: 상태, 원인, 해결책의 체계적 표시
5. **반응형 디자인**: 모바일/데스크톱 호환
6. **데이터 관리**: 로컬 스토리지 활용한 상태 관리

### 🔄 시뮬레이션된 기능
- AI 분석 (랜덤 결과 생성)
- 서버 API (로컬 스토리지 사용)
- 실시간 진행률 (타이머 기반)
