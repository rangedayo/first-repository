# 식물 진단 AI 서비스
사진 한 장으로 식물 상태를 진단하고 해결 방법까지 알려주는 웹 서비스다. 
<br>
<br>
<br>
## 1. 프로젝트 소개  
조그마한 식물 2개를 키우는 식집사로서, 식물 키우는 사람들이 가장 어려워하는 부분은 "왜 식물이 아픈지"와 "어떻게 해야 하는지"를 모른다는 점이다.  

꽃집, 식물정원 가서 직접 물어보는 게 가장 정확하지만, 식집사들이 간단하게라도 문제를 파악해본다면 좋지 않을까 싶은 생각에 '식물 진단 ai 서비스'를 만들어보고자 했다. 식물 사진을 업로드하면 상태를 분석하고 원인과 해결 방법까지 알려주는 웹 서비스를 만드는 것이 목표였다.

처음에는 AI 없이 가짜 분석(시뮬레이션)으로 시작했고, 이후 **Plant.id API**를 연결해서 실제 진단까지 가능하도록 구현했다. 
<br>
<br>
<br>
## 2. 주요 기능  
- 이미지 업로드  
- 식물 상태 분석 (시뮬레이션 → 실제 AI 연동)  
- 원인 분석 (우선순위 포함)  
- 해결 방법 제공 (즉시 조치 / 장기 관리)
<br>
<br>

## 3. 실행 방법  
### 1) 프론트 실행  
```bash
python -m http.server 8000
````
```
http://localhost:8000
```
<br>

### 2) 서버 실행 (AI 기능 사용 시)
```bash
npm install
npm run dev
```
```
http://localhost:3001
```
<br>
<br>

## 4. 기술 스택
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- AI: Plant.id API

## 6. 문제 & 해결
### 1. 페이지 이동 안 되는 문제
- 분석은 완료했지만 다음 페이지로 안 넘어감
- 버튼도 안 눌리는 상태 발생

☞ 해결 :

- 이벤트 재연결
- 모달 완전히 제거
<br>

### 2. Node.js 실행 문제
- node, npm 명령어가 실행되지 않음

☞ 해결 :

- 환경 설정 확인 및 실행 스크립트로 해결
<br>

### 3. localStorage 용량 초과
- API 응답이 너무 커서 저장 실패

☞ 해결 :

- 필요한 데이터만 저장
- URL 파라미터 방식으로 변경
<br>

### 4. API 연동 에러
- Plant.id API 파라미터 오류 발생

☞ 해결 :

- 공식 문서 기준으로 최소 파라미터만 사용
<br>
<br>
<br>

## 8. 후기
처음에는 ai와 프롬프트로 티키타카하면서 화면이 구성되어가는 과정을 즐기면서 "괜찮은데?, 이렇게 다들 시작하는건가?" 싶었다. 하지만 시뮬레이션 돌리면서 성공의 기쁨을 누리던 순간도 잠시였고, 이후로는 ai와 함께 빠져나올 수 없는 에러 잡기 게임에 갇히게 됐다. 버튼 이벤트, 페이지 이동, 데이터 흐름을 파악하는 것도 너무 어려웠고, ai 도움 받아서 에러를 잡는데도 도저히 해결이 안되는거다.<br>
특히 페이지가 안 넘어가는 문제, 모델 api와 서버 연결하는 문제가 너무 어려웠다.<br>
<br>
프롬프트를 어떻게 써야할지에 대한 고민과 이렇게 짧은 시간 안에 이 정도까지 구현해낼 수 있다는 것에 감탄도 했지만, 그와 동시에 ai를 쓰고 있는 사람이 웹의 기본 구조를 제대로 이해하지 않고서는 아무리 좋은 도구를 쓴다해도 문제를 해결할 수 없다는 것이었다. <br>
가장 황당했던 예시로, plant.id API 공식문서를 찾아볼 생각을 안 하고 있었다는 것. 코드 작업을 하면서 항상 느끼는 건, 공부하고 있는 내 태도가 기본이 안 되어있다는 점이다. <br>
꼼꼼히 공부하면서도 빨리 습득해야 ai 속도를 따라잡을 수 있을텐데, 어쩌면 영영 못 따라잡겠지 싶으면서도 포기하고 싶지 않다는 생각도 든다. 더 발전하기 전에 얼른 성장하고 싶다.

그리고 또 한가지 배운 점은, <br>
처음부터 많은 기능이 탑재되도록 설계도를 작성하기보다 “작게 만들고 → 점점 확장하는 방식”이 훨씬 효율적이라는 사실이다. 정말 완벽에 가깝게 ai에게 요구할 수 있을 정도의 설계도라면 모르겠지만, 뭐 하나 펑크나면 많은 비중을 다시 바꿔야하는 상황이 생길 수 있다는 것도 몸소 깨달았다.
